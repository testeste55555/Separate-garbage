1. 目的

40品目APP_READYの安全要件を下げず、オンライン授業で使用する固定画像10品目を優先自治体ごとに早期利用可能にする。

2. readinessの分離

APP_READY:
- 共通40品目すべてを自治体単位でatomicに昇格
- 全条件枝 ITEM_SPECIFIC / COMPLETE
- coverage 40/40 APP_READY
- global APP_READINESS_GATEは全132 active自治体完成までHOLD

LESSON_READY_10:
- item_image_assets.csvのCONFIRMED固定10品目だけを対象
- 10品目の分別先変更・前処理変更に関わる条件枝をすべてCOMPLETE
- 各品目で画像と一致するscoring_branchをちょうど1枝指定
- canonical mappingはVERIFIED / COMPLETE、coverageはVERIFIED / branch_completeness_confirmed=TRUE
- APP_READY自治体数・APP_READINESS_GATEには加算しない
- 残り30品目は未完了状態を維持する

3. 現行LESSON_READY_10

- 19/19条件枝 COMPLETE

M105 廿日市市:
- 10/10画像品目
- 22/22条件枝 COMPLETE
- 現行公式50音表と2026年度版ごみ分別ガイドを正本として使用
- ペットボトル、缶・びん、白色トレイ、古紙、電球、充電池、ライターの条件差を保持
- 白熱電球、蛍光管、LED電球の分別先を統合しない
- 破損・膨張・発熱したリチウムイオン電池は通常BOXへ投影せず、直接搬入の教師用例外として保持
- 使い捨てライターは公式根拠にないガス抜き手順を補わない

4. 自動正誤判定

オンライン授業モードのみ有効。次の両方を必須とする。

- 明示的scopeがAPP_READY又はLESSON_READY_10
- 画像固有mappingがVERIFIEDで、対象reviewのscoring可能枝と一致

学習者画面には品目名、条件、前処理、例外、正解説明、公式出典を表示しない。
