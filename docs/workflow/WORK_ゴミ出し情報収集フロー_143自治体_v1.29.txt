==================================================
0. v1.29の変更
==================================================

M098尾道市・M099福山市について、完全な地域別category taxonomyと、
固定10品目に必要な教材上の地域差を分離する。

新規2層：

1. district_scope
   公式資料上の地域範囲を保持する内部索引。
   学習者へ直接表示しない。

2. lesson_variant_group
   固定10品目の正答・主要箱が実質的に変わる場合だけ分ける教材単位。

M098：6 district_scope → 1 lesson_variant_group
M099：4 district_scope → 3 lesson_variant_group

オンライン授業は固定10品目の採点用BOX、対面授業は主要分別箱を使う。
両者を同じBOX一覧として扱わない。

==================================================
1. UI
==================================================

M098は自治体選択後にそのまま授業画面へ進む。
尾道地域・向島町・御調町・因島地域・瀬戸田町の追加選択は出さない。

M099だけ次の3択を表示する。

・一般地域
・内海町・沼隈町
・走島町

町丁目・袋色・コンテナ細分類は追加選択にしない。

対面授業では、M098・M099とも固定10品目専用BOXではなく、
授業で必要な主要分別箱を表示する。

「資源回収・確認」は自治体正式区分ではない。
福山市の紙類差を必要十分な粒度で示す教材用簡略行動箱として扱う。

==================================================
2. 紙類の安全境界
==================================================

M099一般地域：
・新聞、段ボール → 紙類
・紙パック → 資源回収・確認

M099内海町・沼隈町：
・新聞、段ボール、紙パック → 紙類

M099走島町：
・新聞、段ボール、紙パック → 資源回収・確認

走島町の3品目を通常紙類へ投影しない。
フェリー、持込施設、特殊回収経路は学習者向けBOXへ追加しない。

M098は6内部scopeの固定10品目が同一教材正答セットであることだけを確認する。
I031電球は公式資料上の表記差を教材分類「有害ごみ系」へ正規化する。

内海町と沼隈町は固定10品目上の正答差がないため再分割しない。
制度上の細かな差は教材へ持ち込まない。

==================================================
3. APP_READYとの分離
==================================================

M098/M099の完全taxonomy・40品目APP_READY側はDEFERREDを維持する。
今回のLESSON_READY_10は40品目APP_READYへの昇格ではない。

自治体ID・district_scope_idは再採番しない。
今回の実装では特殊品目・例外経路をこれ以上詳細化しない。
