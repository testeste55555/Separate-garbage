# Pilot Schema Issues

確認日：2026-08-17

## 1. 分別区分と回収経路は別概念

同じ品目でも、集積所、拠点回収、直接搬入、予約戸別収集、販売店回収が併存する。従来の `category_id` だけでは「何に分けるか」と「どこへ出すか」が混ざるため、`collection_channel` を追加した。

## 2. 親区分と下位区分がある

米子市の「古紙類」の下に「新聞・チラシ」「本・雑誌・雑がみ・牛乳パック」「ダンボール・紙箱」があり、港区の「資源」の下に複数資源区分がある。`parent_category_id` と `classification_level` を追加した。

## 3. 同一品目の条件分岐

汚れ、色、材質、サイズ、破損、電池の着脱可否で分別先が変わる。代表品目だけでは復元できないため、`適用条件` と `条件外の扱い` を追加した。

## 4. 粗大ごみの定義が自治体ごとに異なる

広島市は原則30cm以上、港区も最大辺30cm以上だが、米子市は寸法・重量と袋／シール条件、庄原市・山田町は指定袋に入るかが重要。`サイズ・条件` を独立項目にした。

## 5. 「有料」は単純な真偽値では不足

指定袋、収集シール、粗大ごみ処理券、直接搬入手数料など課金単位が異なる。真偽値は検索用に保持し、具体内容は `料金ルール` に保存する。

## 6. 一部事務組合との役割分担

山田町は町が排出ルールを案内し、宮古地区広域行政組合が処理・受入れ辞典を担う。自治体表の `ごみ処理主体` は複数主体を許容し、sourcesで発行主体を資料単位に保持する。

## 7. 現行性と資料発行年が一致しない

庄原市の2022年度発行ガイド、山田町の令和6年資料が2026年度の公式ページから現行資料として案内されている。`対象年度`、`ページ更新日`、`取得確認日`、`現行性` を分けて記録する。

## 8. 多言語資料は言語集合が資料ごとに異なる

単一URLだけでは対応言語と版の差異が分からない。PilotではURLと備考に保持し、本調査で必要になれば `source_languages` の別表化を検討する。

## 9. 穴あけ等の安全ルールが自治体で異なる

スプレー缶は広島市が穴を開けない、庄原市・米子市・山田町が穴あけを案内している。全国共通化せず、自治体別の前処理と確認日を必須にする。
