# Batch 01 Schema Observations

確認日：2026-08-17  
対象Schema：v1.0

## 結論

Batch 01の10自治体はSchema v1.0で格納できたため、Schema変更は行わない。

## 観察事項

### 1. 施行予定日

石巻市は2026年10月1日から「プラスチック」の分別収集を開始予定である。Schema v1.0には `effective_from` / `effective_to` がないため、現行データと将来データを機械的に切り替えられない。

今回の暫定対応：

- `注意事項` に「2026年10月1日施行予定」と記録
- sourceの `現行性` を `施行予定` とする
- `適用条件` に施行日を記録
- municipalityの備考とQAにも同じ境界を記録

次回Schema改訂候補：`effective_from`, `effective_to`, `rule_status`（CURRENT / PLANNED / RETIRED）。

### 2. 複数の収集経路

粗大ごみは「戸別予約収集」と「直接搬入」の両方が選べる自治体がある。現行の `collection_channel` は単一値のため、代表経路を格納し、代替経路を `条件外の扱い`・`注意事項` に記録した。

次回Schema改訂候補：区分と収集経路を多対多で持つ `category_channels` テーブル。

### 3. サイト内翻訳と独立多言語資料

紫波町は公式サイトの翻訳機能、奥州市・大泉町・宇都宮市は独立資料を提供する。現在はどちらも `多言語資料URL` で保持できるが、教材UIでは資料品質と更新管理が異なる。

次回Schema改訂候補：`multilingual_resource_type`（DOCUMENT / SITE_TRANSLATION / APP）。

### 4. 地域限定区分

紫波町の生ごみ、奥州市の衣川地域のみの鉄くずなど、自治体内の一部地域にだけ適用される区分がある。`適用条件` で表現できるためv1.0の範囲内だが、後のアプリ実装では地域条件を表示から落とさないこと。

## 判定

いずれもデータ欠落には至らず、Schema v1.0の固定を維持する。施行日の機械判定は次回Schema改訂の最優先候補とする。
