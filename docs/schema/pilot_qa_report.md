## RED TEAM確認

- 収集曜日・時刻・地区別日程を構造化データへ混入していない。
- 民間まとめサイトを根拠にしていない。外部検索サービスは自治体公式ページから案内されるものだけを記録した。
- 「燃える／燃やせる」「不燃／燃えない」等を全国共通名称へ置換していない。
- スプレー缶の穴あけ方針を全国共通化していない。
- 家庭ごみと事業系ごみを混在させていない。
- `自治体収集外` と `粗大ごみ` を同一扱いにしていない。
- 古い発行年の資料は、2026年度の公式導線で現行案内されていることを明記した。
- 多言語版は補助情報とし、最新日本語公式情報を正とした。

## 次バッチ前の運用条件

1. 10〜15自治体ごとに同じ検証スクリプトと一次QAを実行する。
2. 公式資料が古い場合、現行公式ページからの導線を必ず確認する。
3. `QA_PASSED` は必須参照整合性が通った後にのみ付与する。
