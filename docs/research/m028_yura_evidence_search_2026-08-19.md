# M028 由良町 区分網羅性証拠 再探索記録

実施日: 2026-08-19
対象: M028 由良町
目的: Batch 03の唯一のQA_REQUIREDを、現行一次資料で解消できるか再確認する。

## 結論

M028は引き続き `QA_REQUIRED / NOT_REVIEWED` とする。

由良町公式の現行広報カレンダーから、可燃・プラスチック・不燃・資源・粗大ごみの収集ラベルは確認できる。一方、町公式サイト上でペットボトル・乾電池・古紙等を含む現行の全分別区分索引・冊子・一般廃棄物処理基本計画本文には到達できなかった。

したがって、現行Schema v1.2.3の `MANUAL_INDEX_REVIEW` に必要な「公式目次・見出し・索引を先頭から末尾まで全件照合」という条件は満たさない。

## 由良町公式で確認できたもの

### 2026年3月号 広報ゆら

URL:
https://www.town.yura.wakayama.jp/docs/2025122500014/files/202603.pdf

確認できる収集ラベル:
- 可燃1 / 可燃2
- プラスチック
- 不燃
- 資源1 / 資源2
- 粗大ごみ

可燃1/2および資源1/2は分別種別差ではなく地区グループ差として表示されている。

同資料だけではペットボトル・乾電池・古紙等の扱いを含む全区分体系を証明できない。

## 御坊広域側で確認できたもの

御坊市公式の御坊広域清掃センター案内では、御坊市・美浜町・日高町・由良町・印南町・日高川町のごみを同センターが受け入れることを確認できる。

URL:
https://www.city.gobo.lg.jp/sisei/5296.html

また、御坊広域行政事務組合への公式外部リンクも存在する。ただし、今回取得できた広域側資料は搬入方法・処理困難物等が中心で、由良町住民向けの現行収集区分一覧としては使用できない。

## 政府公式の補助証拠

環境省「御坊周辺地域 循環型社会形成推進地域計画」（計画期間: 令和6年4月1日〜令和11年3月31日）では、構成市町を

- 御坊市
- 美浜町
- 日高町
- 由良町
- 印南町
- 日高川町

と明示し、生活系ごみの分別区分として次を掲載している。

- 燃えるごみ
- 燃える大型ごみ
- 燃えないごみ
- 燃えない大型ごみ
- 資源ごみ
- プラスチック資源
- ペットボトル
- 乾電池
- 古紙等

URL:
https://www.env.go.jp/recycle/waste/3r_network/5_region/project_list/30_wakayama/05_gobo_r6.pdf

同計画は、令和5年2月に構成6市町それぞれが一般廃棄物処理基本計画を策定しており、地域計画の数値・処理体系はそれらを基礎としている旨も記載する。

ただし、この環境省資料は由良町または御坊広域行政事務組合が公開する住民向け現行一次資料ではない。よって、現在のSchema v1.2.3では区分網羅性のPRIMARY_INDEXとしては採用しない。

## 判断

環境省資料は、現在Batch 03に入っている5葉だけでは由良町の体系が不足している可能性が高いことを強く裏付ける。

したがって、証拠不足を理由に5区分だけで `QA_PASSED` へ昇格することはしない。

現状:
- category_count_verified = FALSE
- category_count_check_status = NOT_REVIEWED
- 確認ステータス = QA_REQUIRED
- NEXT_BATCH_GATE = HOLD

を維持する。

## 次の解消条件

次のいずれかを取得できた場合のみ再判定する。

1. 由良町公式の一般廃棄物処理基本計画（令和5年2月策定）の本文
2. 由良町公式の現行ごみ分別冊子・全区分表
3. 由良町公式ページから正式に案内された、御坊広域行政事務組合の由良町適用全区分資料
4. 由良町の現行一般廃棄物処理実施計画等で、全分別体系が明示されたもの

環境省・和歌山県等の二次的な政府資料だけでは、現行Gateを解除しない。
